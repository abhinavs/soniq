# Soniq dashboard

The Soniq dashboard is a built-in web UI that shows queues, workers, job history and failed jobs from your PostgreSQL database. It is read-only by default.

- [Overview](overview.md) - setup, capabilities, read-only and write mode, and API endpoints.
