# Soniq command-line interface

The `soniq` command sets up the PostgreSQL schema, runs workers and the scheduler, and manages job state. Use it to deploy and operate Soniq background jobs from a shell, CI or a container.

- [Commands](commands.md) - full reference for `setup`, `worker`, `status`, `inspect`, `migrate-status`, `migrations export`, `dashboard`, `scheduler`, `dead-letter`, and `tasks-check`.
